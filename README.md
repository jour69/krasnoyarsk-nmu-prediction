# Применение методов машинного обучения для краткосрочного прогнозирования экологических режимов НМУ (г. Красноярск)

## 🌍 Практическая ценность исследования
Проект посвящен разработке автономного программного комплекса на базе искусственного интеллекта для прогнозирования периодов неблагоприятных метеорологических условий (НМУ), известных как режим «Чёрного неба». 

В отличие от традиционных постов наблюдения, фиксирующих смог по факту наступления, система строит упреждающий прогноз на основе чистых метеорологических параметров (температура, атмосферное давление, влажность, скорость ветра). Это позволяет экологическим службам и промышленным предприятиям своевременно вводить превентивные меры и снижать нагрузку на атмосферу до момента критического скопления выбросов в городской котловине.

## 🛠 Инжиниринг признаков и преодоление дисбаланса (Data Engineering)
Для обучения ИИ использовались исторические массивы данных Среднесибирского УГМС. В выборке наблюдается сильный естественный дисбаланс классов: чистые дни составляют около 95%, периоды НМУ — менее 5%. 

Для извлечения физических закономерностей и адаптации моделей к редким событиям был реализован пайплайн признаков:
1. **`danger_wind`** — бинарный маркер приземного штиля (скорость ветра ≤ 1.5 м/с).
2. **`inversion_risk`** — индикатор риска возникновения радиационной инверсии (влажность воздуха U ≥ 80% в сочетании с опасным штилем).
3. **`wind_lag_3h` и `wind_lag_6h`** — временные лаги (историческая память изменений ветра на 3 и 6 часов назад) для учета кумулятивного эффекта накопления загрязнений.

## 📊 Результаты сравнительного анализа моделей (Тестовый сплит 2026 г.)
Для выравнивания весов классов была проведена ручная калибровка предсказательных порогов вероятности в диапазоне `0.51–0.53`. Интегральная оценка качества выполнялась по честной метрике **`Macro F1-Score`**, которая равнозначно оценивает эффективность модели по обоим классам, независимо от их объема в датасете.

| Архитектура ИИ-модели | Выбранный порог | Точность по НМУ (`Precision`) | Полнота по НМУ (`Recall`) | Честный баланс (`Macro F1`) |
| :--- | :---: | :---: | :---: | :---: |
| **📈 Логистическая регрессия** | **0.53** | **4%** | 10% | **0.49** 🏆 |
| **🌲 Случайный лес (Random Forest)** | **0.51** | **4%** | 16% | 0.47 |
| **🚀 Градиентный бустинг (HistGB)** | **0.52** | **4%** | **26%** 🏆 | 0.44 |

### Ключевые аналитические выводы:
* **Линейная стабильность:** Классическая Логистическая регрессия показала наивысшую устойчивость к переобучению на тестовых данных (`Macro F1 = 0.49`). Это подтверждает линейную природу накопления загрязнений при стабильном суточном застое воздушных масс.
* **Полнота перехвата:** Последовательный ансамбль Градиентного бустинга продемонстрировал наибольшую чувствительность к экстремальным аномалиям, успешно обнаружив **26% всех фактических периодов НМУ** в тестовом периоде.

## 💻 Структура программного пайплайна
Код спроектирован в виде лаконичных последовательных блоков для обеспечения полной воспроизводимости эксперимента:
* **Блок 1:** Парсинг входного метеофайла, обход метаданных архивов погоды (`skiprows=6`) и хронологическая разметка целевого маркера (`nmu_status`) по историческим приказам УГМС. Заложена автономная генерация физически точной структуры данных на случай отсутствия исходного CSV-файла.
* **Блок 2:** Временной сдвиг (расчет лагов), интерполяция пропусков через `.ffill().bfill()` и стандартизация матриц признаков с помощью `StandardScaler`.
* **Блоки 3, 4, 5:** Независимое обучение и валидация Логистической регрессии, Случайного леса и Градиентного бустинга с модификацией решающих правил через функцию `predict_proba`.
