# Прогнозирование неблагоприятных метеорологических условий (НМУ) в г. Красноярске с использованием искусственного интеллекта

## 📌 Описание проекта
Данный проект посвящен разработке специализированной ИИ-системы для прогнозирования экологических режимов НМУ («Чёрного неба») в Красноярске. В основе системы лежит ансамблевый подход машинного обучения, нацеленный на максимизацию метрики **Recall** (минимизация пропусков опасных состояний атмосферы).

Проект выполняется на базе центра цифрового образования **«IT-Куб»** при поддержке научных кураторов.

## 🛠 Технический стек ИИ-платформы
* **Ядро системы:** Python 3 (Google Colab)
* **Предобработка Big Data:** Pandas, NumPy
* **Архитектура ИИ-моделей:** Scikit-Learn

## 📊 Валидация и Структура Данных
Модель обучается на реальных исторических данных метеостанции Красноярск (**WMO_ID=29574**). Целевая ИИ-разметка (`nmu_status`) верифицирована по официальным релизам Среднесибирского УГМС.

Для честной проверки ИИ применено разбиение данных по времени (**Time-Series Split**):
* **Обучающий датасет (Train, 2024–2025 гг.):** 5 685 интервалов (221 точка НМУ)
* **Тестовый датасет (Test, 2026 г.):** 2 205 интервалов (89 точек НМУ)
* *Специфика задачи:* Экстремальный дисбаланс классов (критические ситуации составляют ~4% от общего объема данных).

## 📈 Этап 1: Результаты базового ИИ-модуля (Baseline v1.0)
В качестве стартовой архитектуры ИИ был развернут базовый линейный классификатор со встроенным ИИ-взвешиванием редких классов (`class_weight='balanced'`). Модель анализирует приземные предикторы: температуру воздуха и эффект штиля (скорость ветра ≤ 1 м/с).

### Метрики ИИ-модуля на тестовом датасете (2026 г.):
```text
              precision    recall  f1-score   support

       Чисто       0.95      0.70      0.80      2116
         НМУ       0.02      0.13      0.03        89

    accuracy                           0.67      2205
```

**Анализ первой итерации:** Достигнутый показатель **Recall (13%)** показывает границы приземных признаков. Для качественного скачка ИИ-системе необходим глубокий инжиниринг признаков вертикального профиля атмосферы.

## 🚀 План развития ИИ-системы
1. **ИИ-Модуль v1.5 (Feature Engineering):** Интеграция математического алгоритма фиксации температурной инверсии («теплового купола» над городом).
2. **ИИ-Модуль v2.0 (Ансамбли):** Переход на сложные нелинейные ИИ-архитектуры — Случайный лес (*Random Forest*) и Градиентный бустинг (*Gradient Boosting*).
