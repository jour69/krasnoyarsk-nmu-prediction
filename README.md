# Прогнозирование неблагоприятных метеорологических условий (НМУ) в г. Красноярске с использованием искусственного интеллекта

## 📌 Описание проекта
Данный проект посвящен разработке специализированной ИИ-системы для краткосрочного прогнозирования экологических режимов НМУ («Чёрного неба») в Красноярске. В основе системы лежит машинное обучение, нацеленное на максимизацию метрики **Recall** (минимизация критических пропусков опасных состояний атмосферы).

Проект выполняется на базе центра цифрового образования **«IT-Куб»** при поддержке научных кураторов.

## 🛠 Технический стек
* **Язык разработки:** Python 3 (Среда Google Colab)
* **Предобработка Big Data:** Pandas, NumPy
* **Архитектура моделей:** Scikit-Learn

## 📊 Структура данных и ИИ-Валидация
Модель обучается на реальных исторических данных метеостанции Красноярск (**ОПМС, WMO_ID=29574**). Целевая ИИ-разметка (`nmu_status`) полностью верифицирована по официальным релизам Среднесибирского УГМС.

Для предотвращения утечки данных из будущего применено честное разбиение временного ряда (**Time-Series Split**):
* **Обучающий датасет (Train, 2024–2025 гг.):** 5 685 строк (из них точек с НМУ — 280)
* **Тестовый датасет (Test, 2026 г.):** 2 205 строк (из них точек с НМУ — 149)
* *Специфика данных:* Наблюдается экстремальный дисбаланс классов (события НМУ составляют всего ~4-6% датасета).

## 📈 Результаты разработки

### Модуль v1.0 (Приземный Baseline)
Первая итерация линейной модели на базовых признаках (температура и штиль) показала крайне низкую способность находить смог.
* **Recall по НМУ:** 13%

### Модуль v1.5 (Интеграция ИИ-предикторов физики атмосферы)
В датасет был интегрирован кастомный алгоритм Feature Engineering для фиксации эффекта «тепловой крышки» (инверсионного риска на основе штиля ≤ 1.5 м/с, влажности U ≥ 80% и зимней сезонности). 

**Итоговые метрики ИИ-модуля v1.5 на тестовой выборке (2026 г.):**
```text
              precision    recall  f1-score   support

       Чисто       0.97      0.74      0.84      2056
         НМУ       0.15      0.64      0.25       149

    accuracy                           0.73      2205
```

**Вывод этапа:** Внедрение физических признаков инверсии подняло способность ИИ обнаруживать смог с **13% до 64%**!
