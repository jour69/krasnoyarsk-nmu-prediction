# krasnoyarsk-nmu-prediction
Machine learning project for forecasting adverse weather conditions (Black Sky) in Krasnoyarsk
# Прогнозирование режимов НМУ ("Чёрного неба") в Красноярске с помощью Machine Learning

## 🎯 Цель проекта
Разработка прогностической модели машинного обучения (Machine Learning) для заблаговременного предсказания неблагоприятных метеорологических условий (НМУ) в городе Красноярске на основе исторических метеорологических данных. 


## 🧠 Используемый стек технологий
* **Language:** Python 3
* **Data Engineering:** Pandas, NumPy
* **Machine Learning Models:** Scikit-learn (Random Forest Classifier, Logistic Regression)
* **Development Environment:** Google Colab / Jupyter Notebook

## 📊 Структура текущего прототипа (v1.0)
В репозитории опубликован первый рабочий прототип модели (`prototype_v1.py`), реализующий:
1. **Data Cleaning:** Автоматическое восстановление пропусков в метеоданных с помощью вычисления средних значений (функция `.fillna()`).
2. **Feature Extraction:** Разделение входных параметров атмосферного слоя (X) и целевой переменной статуса смога (y).
3. **Model Fitting:** Обучение ансамблевого алгоритма Случайного леса (Random Forest).
4. **Validation Check:** Тест-драйв модели на контрольной выборке с автоматическим расчетом ложноположительных ошибок (**False Positive**).
5. **Feature Importance:** Оценка математического веса и влияния метеопараметров на итоговое решение ИИ.

## 🏁 Текущие результаты анализа важности признаков
Первичные тесты на симуляционном массиве данных показали, что ключевым триггером для модели является падение скорости ветра ниже критической отметки в 1.0 м/с (штиль), что полностью согласуется с климатическими особенностями Красноярской котловины.
